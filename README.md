# VideoLib

桌面视频管理工具 —— 用 PyQt6 + SQLite 管理硬盘上的视频文件，支持多目录索引、增量监控、中文全文搜索、分类与收藏、断点续播。

## 功能特性

- **多根目录索引**：可扫描多个目录，全库为所有目录的并集；`size + mtime` 增量比对，重扫已记忆目录秒级完成
- **增量监控**：watchdog 实时监听当前目录，新增/删除/改名/修改 2 秒防抖自动同步；**支持同时监控多个扫描目录**（缺失目录自动跳过并提示，不影响其余监控）
- **元数据提取**：PyAV 读取时长、分辨率、编码，全部入库
- **缩略图**：纯 PyAV 懒生成（170x96 显示 / 2x 像素高分屏适配），后台线程池，失败自动记录日志并允许重试（0 字节或旧分辨率坏图自动重生成）；已加载缩略图内存缓存（上限 2000 张）；右键「重新生成缩略图」强制重建；**取样模式可选**（设置对话框：随机帧 10%-90% / 固定帧前 5%，只影响新生成）
- **中文全文搜索**：FTS5 全文 + LIKE 兜底，300ms 防抖搜索栏
- **分类管理**：层级分类树（右键增删改），分类按扫描目录隔离，「所有目录」视图按扫描目录分组显示全部，支持批量归类
- **播放**：mpv.exe 子进程内核（named pipe IPC + 子窗口 d3d11 渲染，Win32 物理像素自适应高分屏），断点续播（含 mpv 0.38+ loadfile 新签名适配）+ 播放历史（最近播放视图），Enter/Space 快捷键；键盘控制（←/→ 快退快进 ±5s、↑/↓ 音量、R 倍速循环、F 全屏、Esc 退出/退出全屏）；**播放队列**（⏮⏭ 切换，循环:全部 播完自动续播并回卷）；**倍速**（0.5x–2.0x 循环，切视频不重置）；**全屏**（F/双击视频区，全屏时 Esc 先退全屏）；**音量记忆**（settings.json）；**静音与循环**（M 键/按钮静音，L 键/按钮循环切换：关/单曲/全部——关=播完停在最后一帧，单曲=自动重播，全部=播完续播回卷）；**断点标记**（时长列 ⏵ 前缀标识可续播，悬停显示续播位置）；**清空播放历史**（工具栏入口，二次确认，断点续播位置一并清除）
- **收藏夹**：命名收藏夹（自动补前缀「收藏夹_」），右键批量收藏/移除
- **历史目录管理**：「仅移除记录」（保留视频）/「删除并清除数据」（**后台线程执行 + 进度对话框可取消**，级联清除视频、缩略图与分类树；历史目录记录最后一步才删除——中途中断/取消后可重新选择，幂等清理残留）双选项；父子目录历史互斥（注册/删除自动去重）
- **清理所有目录**（工具栏）：两次确认后后台清空库内**全部**视频条目与缩略图（级联清播放历史/收藏/分类关联），源文件不动、历史目录与数据库备份保留、进度可取消；历史记录已删的孤儿残留条目也可用此功能清除
- **列表交互**：虚拟滚动、固定行高 + 悬停 tooltip、**鼠标悬停整行高亮**、行内播放按钮、批量操作、打开所在文件夹；**视频信息面板**（右键「ℹ 视频信息」：完整路径/大小/时长/编码/分辨率/加入修改时间/所属分类与收藏夹/续播位置，支持复制路径与定位文件）；**排序**（自然键 `v2 < v10`，表头点击，状态记忆）；**窗口/列宽记忆**；**单文件删除**（右键「从库中移除」留盘 /「删除文件并移入回收站...」二次确认）；**标记为已看完**（右键清除断点，保留最近记录）；**复制路径/文件名**（多选换行分隔）；状态栏常驻显示当前视图视频数
- **库统计**：工具栏「统计」按钮（总数/总时长/总大小/各目录/各分类）
- **重复视频检测**：工具栏「查找重复」按钮（相同大小 + 时长相差 ≤2 秒，分组列出文件路径）
- **拖拽**：拖入目录 = 扫描索引；拖入视频文件 = 单文件入库；拖动列表行到分类树 = 批量归类
- **界面主题**：自动跟随系统深浅色（浅蓝柔和 / 深色钢蓝两套配色，Windows 注册表深浅判定），悬停整行高亮、选中低饱和蓝（B 通道下调不刺眼），按钮/菜单/滚动条圆角打磨；**设置对话框可手动覆盖**（跟随系统/浅色/深色，确定即时生效并记忆）
- **设置**：工具栏「设置」对话框——主题切换、音量记忆、备份保留份数、缩略图取样模式（随机帧/固定前 5%）
- **格式支持**：常见视频格式 + `.bin`（内容嗅探：仅含真实视频流的 `.bin` 入库，固件/ROM/数据文件自动跳过）

## 环境要求

- Python 3.14+
- Windows（打包脚本为 `.bat`；代码本身跨平台，仅打包与资源管理器集成依赖 Windows）

## 安装与运行

```bat
pip install -r requirements.txt
python main.py
```

常用 CLI 命令：

```bat
python cli.py index "E:\视频"   :: 命令行全量索引一个目录
python cli.py stats             :: 查看库统计
```

## 打包为单文件 exe

```bat
build.bat
```

生成 `dist\VideoLib.exe`（约 118MB，免 Python 环境，内含 mpv 播放内核）。换机运行只需拷贝这一个文件，首次启动会自动创建数据目录。

## 数据目录

默认位于 `C:\Users\<用户名>\.videolib\`：

| 文件 | 说明 |
|------|------|
| `videolib.db` | SQLite 数据库（WAL 模式，含 FTS5 全文索引） |
| `thumbs/` | 视频缩略图 |
| `settings.json` | 设置（当前监控目录等） |
| `backups/` | 数据库自动备份（启动每日一份 + 删除操作前强制快照，保留最新 5 份） |
| `crash.log` / `thumbnails.log` | 崩溃与缩略图失败日志 |

工具栏「备份与还原 ▾」：立即备份 / 从备份还原... / 打开备份文件夹。还原流程：先自动备份当前库 → 清空缩略图（防 video id 复用显示旧图）→ 用所选框覆盖现场库 → 自动重启应用。手动还原亦可把 `backups/videolib-*.db` 复制为 `videolib.db`（需先删除 `-wal`/`-shm`）后重启。

换机迁移：拷贝整个 `.videolib` 目录到新机器即可保留数据。可用环境变量 `VIDEOLIB_HOME` 指定数据目录（便于测试隔离）。

## 开发

```bat
python -m pytest tests -q     :: 运行测试（198 个用例，约 7 秒）
```

测试基础设施：`tests/conftest.py` 提供共享 fixture（session 级 `qapp`、`repo`、`app_env`/`backup_env` 环境隔离、备份目录隔离），`tests/helpers.py` 提供 `make_test_video` / `wait_for` / `mk_video` 通用辅助；watcher 测试用可参数化的短防抖/短轮询（`WatcherThread(..., debounce=0.2, poll=0.05)`）避免真实 2s 等待。

### 目录结构

```
videolib/
├── main.py                  # 入口
├── cli.py                   # 命令行工具（index / stats）
├── config.py                # 路径、扩展名、设置读写
├── domain/                  # 数据层（models + SQLite 仓库，唯一 SQL 入口）
├── services/                # 扫描、元数据、缩略图、增量监控
├── ui/                      # PyQt6 界面（主窗口、列表、播放器、分类树、对话框）
└── tests/                   # pytest 测试
```

分层约定：UI 只调用 services / repository，repository 只碰 SQLite。

## 技术栈

PyQt6 · SQLite（WAL + FTS5）· PyAV · mpv（播放内核）· watchdog · PyInstaller · pytest
